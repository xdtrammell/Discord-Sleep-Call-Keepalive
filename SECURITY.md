# Security policy

This is a small, unsigned community utility. It does not contact the network, store credentials, or alter Discord's files. It does inject an F15 keyboard event during qualifying idle periods, which is intentional and visible to applications that inspect synthetic input.

If you find a security issue, please avoid posting exploit details in a public issue. Use GitHub's private vulnerability reporting for this repository if enabled, or contact the repository owner privately through GitHub. Do not include passwords, Discord tokens, or unredacted personal logs in reports.

Smart App Control may block unsigned local builds. This repository does not provide a code-signing certificate or claim to be officially trusted by Windows.
